MATLAB Implementations of EAO and IEAO

This repository provides the MATLAB optimizer functions accompanying the manuscript “An Improved Enzyme Action Optimizer for Parameter Identification of the Lorenz Chaotic System”.

Files:

- EAO.m: MATLAB implementation of the Enzyme Action Optimizer used as the baseline.
- IEAO.m: MATLAB implementation of the proposed Improved Enzyme Action Optimizer.

The optimizer functions require a user-supplied objective function and search settings. The repository provides the optimizer implementations; the Lorenz experiment scripts and the complete comparative evaluation workflow are not included.

For the original EAO method, see Rodan et al. (2025), “Enzyme action optimizer: a novel bio-inspired optimization algorithm”, DOI: https://doi.org/10.1007/s11227-025-07052-w.
