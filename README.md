# MATLAB Codes for IEAO-Based Benchmark Evaluation

This repository contains the MATLAB source codes used for implementing and evaluating the Improved Enzyme Action Optimizer (IEAO) together with the original Enzyme Action Optimizer (EAO).

The codes are provided to support the reproducibility of the algorithmic implementation and benchmark-based numerical evaluations reported in the manuscript.

## Files

- `IEAO.m`: MATLAB implementation of the proposed Improved Enzyme Action Optimizer.
- `EAO.m`: MATLAB implementation of the original Enzyme Action Optimizer used for comparison.
- `Get_F.m`: Function-definition file containing benchmark function details, including search bounds, dimensional settings, and objective function handles.
- `bench_functions_plots.m`: Script for plotting or visualising the benchmark functions used in the numerical evaluation.

## Requirements

The codes were prepared for MATLAB. All files should be placed in the same working directory before running the scripts.

## Usage

1. Download or clone this repository.
2. Open MATLAB.
3. Set the MATLAB current folder to the repository directory.
4. Run the required script or call the optimizer functions from MATLAB.
